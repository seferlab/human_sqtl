# This repository contains tools for applying the analysis in paper "Analysis of chromatin structure reveals the connection between sQTLs and the splicing of distant genes" 

 The codebase includes Python implementations. Some of the datasets
 are uploaded, but some of them could not be directly pushed to Github repository.

## Prepare SQTL dataset for analysis
```bash
python preparedata.py
```

## Run analysis
```bash
python sqtlanalyze.py
```

## Generate Plots
```bash
python plotgen.py
```
